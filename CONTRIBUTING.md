# Contributing to CAIRN Trust Fabric

Thank you for your interest in CAIRN Trust Fabric!

## How to Contribute

1. **Bug Reports & Feedback**: Please open an issue using the [Bug Report Template](.github/ISSUE_TEMPLATE/bug_report.md).
2. **Feature Requests & Proposals**: Please submit a proposal using the [Feature Request Template](.github/ISSUE_TEMPLATE/feature_request.md).
3. **Documentation & Examples**: We welcome contributions to integration examples, documentation guides, and sandbox policy recipes.

## Security Disclosures

For security-sensitive vulnerability reports, please follow the guidelines in [SECURITY.md](SECURITY.md) instead of opening a public issue.

## Code of Conduct

All contributors and participants are expected to uphold a respectful, professional, and welcoming environment.
