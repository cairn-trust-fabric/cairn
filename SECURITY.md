# Security Policy

## Supported Versions

| Version | Supported          |
| ------- | ------------------ |
| 1.0.x   | :white_check_mark: |

## Reporting a Vulnerability

We take the security and integrity of CAIRN Trust Fabric with utmost seriousness. If you discover a potential vulnerability, please report it responsibly:

1. **Email**: Send detailed findings to [security@cairnetp.com](mailto:security@cairnetp.com).
2. **Details to Include**:
   - Component affected (e.g. Ingress filter, Docker container runtime, Windows Sandbox VM dispatcher).
   - Reproduction steps, proof-of-concept script, and environment details.
   - Any proposed remediation.
3. **Response Timeline**:
   - Initial acknowledgement: Within 24 hours.
   - Triage and severity assessment: Within 72 hours.
   - Patch release and disclosure coordination: Coordinated with reporting party.

Please do not open public GitHub issues for security vulnerabilities.
